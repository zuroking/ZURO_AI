## [0.1.0]

Первый выпуск.

### Добавлено
- Написанный вручную GPT только с декодером (~15,3 млн параметров) на примитивах
  `torch.nn`: `CausalSelfAttention`, `MLP`, `TransformerBlock`, `MiniGPT`.
- Байтовый BPE-токенизатор (`train_bpe`) и тонкая обёртка `KronosTokenizer` с
  фиксированными специальными токенами (`<pad>`, `<unk>`, `<bos>`, `<eos>`).
- Конвейер данных: источник корпуса Gutenberg с удалением/нормализацией шаблонного текста,
  разбиение train/val по книгам и упаковка в memmap `uint16`.
- Цикл обучения с приоритетом CPU: накопление градиента, autocast в `bfloat16`,
  косинусный график с прогревом, обрезка градиента, чекпоинты и журналирование метрик в
  JSONL.
- Генерация с KV-кэшем и сэмплированием по температуре / top-k / top-p / штрафу за повторы.
- `ConversationBuffer` с обрезкой по границам предложений для чата.
- CLI `kronos_synapse`: `tokenize`, `train`, `eval`, `chat`.
- Юнит-тесты для форм модели, каузальной маски, внимания/KV-кэша, упаковки и буфера
  разговора.
